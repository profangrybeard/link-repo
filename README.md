# Link Repo

## 👉 [Open the Link Repo → profangrybeard.github.io/link-repo](https://profangrybeard.github.io/link-repo/)

**Students: that link above is what you want.** It opens the searchable page with every link in it. The files below just build that page, so you don't need to download or open anything here.

---

## What this is

A curated list of links for my game development courses: software downloads, engine docs, tutorials, and reference material I point to in class. Instead of hunting through old announcements, you can bookmark this one page.

## What's in it

| Category | What you'll find |
| --- | --- |
| **Software & Setup** | Downloads for Unity, Visual Studio, Blender, Photoshop, Krita, source control, and utilities |
| **Course Projects** | Tutorials for specific class projects (Frogger in Unity, the Blender donut, physics materials) |
| **Unity** | Setup, scripting, UI, physics, starter assets, profiling, and longer tutorials |
| **Unreal** | Tutorial sites and community documentation |
| **Blender** | The manual, shortcuts, beginner tutorials, and FBX export help |
| **Game Capture** | Recording gameplay with OBS and editing it in DaVinci Resolve |
| **Visual Reference** | Color palettes, shot composition, cinematography, and character model sheets |
| **Physics for Games** | Plain-language explanations of Newton's laws, friction, and bounce |
| **Game Design** | Essays and games about design theory |

## Using the page

- **Search:** type in the search box, or press <kbd>/</kbd> to jump to it. It matches link titles and web addresses, so a word like `unity3d` or `blender` narrows the list quickly.
- **Browse:** click a category to open it, or use **Expand all** to see everything.
- **Links open in a new tab**, so you won't lose your place.

## Found a broken link or have a suggestion?

Tell me in class or send me a message, and I'll update the page.
